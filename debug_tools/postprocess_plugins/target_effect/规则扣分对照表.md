# 倒计时卡片评分 · 规则扣分对照表

> 依据：6 样本批跑 `batch_20261110_200000_7e5a1b2c`（插件 1.4.0，rubric v4）；2026-11-11 在本机
> 8890 工作台按 `target-dom-v2` 证据重跑后实测。v3 列是同一批数据按旧「÷75×100」口径的分数，
> 仅供对照。权重自 40/25/25 调整为 25/37.5/37.5 后，v4 把三个维度固定为 100 分、不适用维度记 0 分。
> 用途：一眼看清“哪条规则在扣、为什么扣、扣得对不对”。
> 配套文档：[评分规则与扣分明细.md](./评分规则与扣分明细.md)

## 0. 先记住三句话

1. 总分不是“所有规则平均”，而是三个维度直接相加：目标 25 / 可见性 37.5 / 规范 37.5，恒定 100 分。
2. **单条规则的分值 = 维度权重 ÷ 该样本适用规则数**，所以同一规则在不同样本上的分值会变。
3. 当前 6 个样本：目标维度不适用（没有显式期望），记 0/25；可见性 6 条、规范 17–19 条；
   总分 = 0 + 可见性得分 + 规范得分，页面上三项相加就是总分。

当前单条参考值：

| 维度 | 权重 | 当前适用条数 | 单条分值 | 说明 |
|---|---:|---:|---:|---|
| 目标语义 | 25 | 0 | — | 没有 `expectations.json`，整维记 0/25 |
| 可见性 | 37.5 | 6（去重后） | ≈ 6.3 | 每条 fail 扣 6.3，pending 扣 3.1 |
| 规范符合 | 37.5 | 17–19 | ≈ 2.0–2.2 | 某条 NA 后，其余条的单条分值会升高 |

## 2. 可见性维度（37.5 分，当前 6–7 条）

判定对象是**渲染后的 DOM 和截图**，不是 DSL 声明值。

| 规则 | 查什么 | 什么情况扣 | 证据 | 规范依据 | v2 实测 | v3 处理 |
|---|---|---|---|---|---|---|

| `VIS.TEXT_OVERFLOW` | 文字跑出卡片 | 文本矩形超出画布 | DOM | §1 内容不得越界 | 通过 | 保留 |

2026-11-11 新增三条几何诊断（`target-dom-v2` 证据才产出，不进入评分前缀，也不影响样本状态）：

| 规则 | 查什么 | 什么情况触发 |
|---|---|---|
| `LAYOUT.CARD_OVERFLOW` | 可见节点内容矩形是否越出卡片，且没有被祖先裁切 | 越界 > 2px 且该方向无 `overflow: hidden/clip` → pending |
| `LAYOUT.PARENT_CLIP` | 非文本、非装饰节点是否被中间容器裁切 | 最近裁切祖先不是 Stack / RelativeContainer / AbsoluteLayout → pending |
| `LAYOUT.SIBLING_OVERLAP` | 同父兄弟节点是否遮挡 | 图文之间存在 > 2px 交集且占较小节点面积 > 12% → pending |

## 7. 规范外 / 重复 / 矛盾清单

| 类型 | 涉及规则 | 说明 | 状态 |
|---|---|---|---|
| 矛盾 | `TITLE_ELLIPSIS` ↔ `TEXT_CLIPPED` | 前者要求省略号，后者把省略号判成裁切 | v3 已修：只判横向；标题省略号失败时裁切不再重复扣 |
| 重复 | `MASK` / `TITLE_COLOR` ↔ `CONTRAST_LOW` | 缺蒙层、颜色不对，对比度必然低 | v3 已修：根因失败且节点被完全覆盖时对比度不适用 |
| 重复 | `PADDING` ↔ `SAFE_AREA` | 同一 12vp 边距，声明和结果各扣一次 | v3 已修：同时失败只计安全区 |
| 重复 | `SAFE_AREA` ↔ `TEXT_OVERFLOW` | 跑出卡片时两级都失败 | v3 已修：溢出节点不再计入安全区 |
| 重复 | `SPEC.*_FONT` ↔ `FONT_TOO_SMALL` | 极端小字号两条都扣 | v3 已修：节点被 SPEC 字号完全覆盖时不再计入 |
| 规范外 | `TEXT_OVERLAP`、`FONT_TOO_SMALL` | 规范没有对应要求 | 待定，见 §9 |
| 规范外 | `ACTION_PATTERN`、`BG_SINGLE` | 设计规范没有对应要求 | 待定，见 §9 |
| 规范未确认 | 2×4 的 9 根柱体、合并单位、图案数量 | 规范自己标注为推导值/未定义；图案数量已暂不扣分 | 图案数量暂记 NA，待具体 DSL |

去重只处理“同一根因的派生症状”；上面标为待定的项是“规则本身是否该计分”，
不属于重复扣分，本轮没有调整。

## 9. 需要你拍板的点

1. 对比度算不算规范？→ v3 已按“根因失败时不重复”处理；是否进一步降为诊断仍可再议。
2. 标题省略号与裁切的边界？→ v3 已只判横向裁切。
3. `ACTION_PATTERN`、`BG_SINGLE` 是产品规则还是设计规范？→ 若不是设计规范，挪出 SPEC。
4. 图案数量怎么判？→ 已暂按不扣分处理，只记录柱体/圆球数量；圆点=当月天数、柱体=一周天数的映射，待拿到具体图案 DSL 后再实现。
5. 单条分值继续随适用条数浮动，还是改成固定分母？→ 建议保留动态，但报告里显示“本样本适用条数”。
