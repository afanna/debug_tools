### 渲染塌陷问题与修复（重要）
- 现象：卡片只显示 root 蓝色底，内容看不到。
- 根因一：`.node-Stack` 用 `display:grid` + `grid-template-areas` 但未定义行列尺寸，grid 行高被内容撑成 42px，导致 `height:matchParent` 的 `__post_theme_foreground` 只解析到 42px。修复：`grid-template:minmax(0,1fr)/minmax(0,1fr)` + 子项 `grid-area:1/1`，让子项铺满 Stack 内容盒。
- 根因二：为显示 IMG 角标给 `.node-Image` 加了 `position:relative`，定位元素会绘制在所有非定位元素之上，结果背景图盖住文字层和融球。修复：去掉定位与伪元素，改用 background-image 斜纹表示图片占位（纯背景绘制，不参与层叠）。
- 根因三：`__post_theme_background` 的 children 是 `[fusionBallBackground, __post_theme_base]`，基底图排在融球之后会盖住融球。修复：Stack 渲染时把 `__post_theme_base` 前缀节点排到最前（底层）。
- 验证方式：`document.elementFromPoint` 应命中 `primary_main` 而非 `__post_theme_base`；截图确认 Q001 显示上海市/29℃/多云/良，Q004 显示融球（240×240、rgb(43,101,217)、radius 80px）与日历文字。

## 按真实运行时校正 demo 渲染（覆盖上节「根因三」的结论）
- 用户提供的搬家倒计时 DSL 已作为默认样本内嵌（共 9 个样本）。新增映射：拼接表达式 `{{ '搬家 ' + ${/data/...} }}`、`wrapContent`、对象形式 `padding`、对齐 `bottom/bottomEnd`、Button 用 `label`、Icon 用 `fillColor`。
- **协议口径**：`docs/鸿蒙桌面卡片A2UI协议完整规范.md:1196` 明确 Stack「子组件按顺序叠放，后添加的在上层」。所以 `__post_theme_background` 的 `[fusionBallBackground, __post_theme_base]` 是**故意**让真实底图盖在融球上；融球是图片素材加载失败时的兜底层（云侧 `theme_photo_processing.py:156` 把 fusion 插到 index 0，`gallery_background.py:83-88` 校验该顺序）。之前「把 base 排到最前」的做法是错的，已撤销。
- **真实运行时口径**（`debug_tools/card_renderer/runtime/components/src/extended/ExtendedLayouts.tsx:160-178`）：ExtendedStack 是 `position:relative` + 每个 child 一个 `position:absolute;inset:0;display:flex` 的 wrapper（pointer-events:none），`alignContent` 映射成 wrapper 的 justifyContent/alignItems（含 Start→flex-start / End→flex-end / top→flex-start / bottom→flex-end / 其余 center），子项 `__stackChild` 设 pointer-events:auto + flex-shrink:0。百分比尺寸相对这个满尺寸 wrapper 解析。此前 demo 用 grid 同 cell，把 `alignContent` 当 grid 行对齐，导致三个融球 x/y 全为 0 堆在左上角。
- 其它对齐项：`mergeCommonStyles`（common-styles.ts:111-）里 `wrapContent→max-content`、`height:matchParent→100% + alignSelf:stretch`、`backdropBlur.radius→blur(Npx)`、`padding:{top,right,bottom,left}` 映射四边；`ExtendedRow` 默认 `align-items:center`、`ExtendedColumn` 默认 `stretch`；`itemMargin` 只作用于 Row/Column/List 的 gap。Image 用真实 `<img>`（外部 URL 浏览器直连），小尺寸 svg + `fillColor` 用 CSS mask 着色。
- demo 现在：把倒计时主题底图 jpg 与 3 个本地 svg 转 data URI 内嵌（`ASSETS`），底图加载后用 canvas 取 16×16 平均色写回节点 backgroundColor，让检查器的对比度判定读「有效背景色」而不是占位色；顶栏三态开关「真实素材 / 缺失·融球 / 融球结构（关玻璃层）」用于同时看保真渲染与兜底层结构（`backdropBlur 210` 会把融球糊成纯色）。新增 `Alt+点击` 用 `elementsFromPoint` 逐层穿透选中被前景遮挡的背景层。
- 验证（Edge headless + playwright，无 pageerror）：融球几何 `large(-22,-124,315×315)` / `medium(-60,90,240×240)` / `small(143,135,150×150)`，玻璃层 `blur(210px)`；底图 `img.complete=true, 600×600`、平均色 `rgb(114,143,232)`；9 个样本文字与根尺寸全部正常，Q001/Q004 显示真实底图；缩放 100%/150% 四边读数一致；点击、判定、fontSize 18→26 回写、导出、Alt 穿透均通过。
- 教训：demo 的 CSS 映射要照抄 `card_renderer/runtime` 的 `Extended*`，不要自己发明 Stack 语义；改动前先查协议规范与真实渲染器，尤其层叠顺序与 alignContent。
